# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately through GitHub:
[Report a vulnerability](https://github.com/tinytankphp/framework/security/advisories/new)
(the repository's **Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it (a minimal site or a test is ideal), the TinyTank
version (`composer show tinytank/framework`) and what an attacker could do with it. We aim to reply
within a week, and will agree with you on a fix and a disclosure date before anything is published.

Problems in the skeleton (tinytankphp/tinytank) or the docs can be reported here too.

## Supported versions

TinyTank is in beta (0.x). Security fixes go into the latest release only: keep sites updated with
`composer update tinytank/framework`.
